# My Currency Converter

A desktop currency converter built with Python and Tkinter.

## Features

- Simple graphical user interface
- Select source and target currencies
- Convert an entered amount
- Swap the selected currencies
- Clear the amount and result
- Input validation and error handling

## Technologies Used

- Python
- Tkinter
- CurrencyConverter Python library

## Requirements

- Python 3
- pip

## Installation

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Install the required dependency:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python main.py
   ```

## Usage

1. Select the source currency.
2. Select the target currency.
3. Enter the amount.
4. Click **Convert** to see the result.
5. Use **Swap** to switch currencies or **Clear** to reset the input and result.

Exchange results depend on the rate data available to the installed library and may not represent live market rates.
